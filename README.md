## 支付宝付款失败了怎么处理？

绝大多数失败是临时性的，处理顺序：先重试，不行换银联，钱扣了没开通就提工单。

**页面加载不出来或扫码报错。** 支付宝的跨境收银台偶尔抖动，刷新几次或隔几分钟再试即可。提示“系统繁忙”也不用急，订单会保留 24 小时，换个时段或者直接换银联接着付。

**接口故障。** 搬瓦工的支付宝接口历史上出现过短暂故障，比如 SECONDARY_MERCHANT_STATUS_ERROR 这类报错，通常几小时内自动恢复。等不及就换银联——银联走官方收银台，稳定性比支付宝还高。

**支付宝已扣款，订单却显示未支付。** 少见但确实发生过：钱扣了，搬瓦工系统没收到通知。这时提交 Support Ticket，把支付宝订单号发给客服，人工核实后要么开通要么退款，不会钱打水漂。
